About Me

Saya adalah siswa jurusan PPLG yang berfokus pada pengembangan perangkat lunak lintas platform, mulai dari situs web, aplikasi mobile, hingga pengalaman game interaktif. Pengalaman & Fokus Belajar Web & General Development Menggunakan VS Code sebagai code editor utama untuk eksplorasi logika pemrograman dan pembuatan situs web. Mobile Application Development Memahami dasar alur pembuatan aplikasi Android menggunakan MIT App Inventor (berbasis blok). Mengembangkan kemampuan ke tingkat lanjutan menggunakan Android Studio untuk aplikasi yang lebih kompleks. Game Development Bereksperimen dengan logika gameplay, scripting mekanik, dan desain lingkungan interaktif 3D menggunakan Roblox Studio. Saya selalu bersemangat untuk bereksplorasi dengan teknologi baru dan siap mengaplikasikan keahlian ini dalam proyek-proyek nyata.

Beberapa teknologi yang sering saya gunakan:

HTML & CSS MIT APP Inventor Roblox Studio My SQL Git & GitHub
